# 三条参考片的骨架

学这个风格用的三条混剪。片子本身、逐镜头全文都留在作者本地，这里只放做片时用得上的骨架：每段讲什么、怎么剪、镜头时长、开头高潮结尾、各自的 5 条规矩。`references/` 里引用的"A 3.25 秒""D #44"都能在这里对上。

三条片各是一种片型，**骨架不同，判断相同**：先有一句话；结构挂在音乐上；长镜头只给立论、急停和落点；特效只在门上；结尾回到开头。

---

## A 名单式（17.4 秒，"请选择你的英雄"）

一份"坏女孩 / 疯女人英雄榜"。片头 2 秒把十几个角色当成游戏角色卡亮出来，进鼓以后**一小节（约 1.9 秒）给一个角色、一句自我宣言**，8 小节，最后收成一句复数的"我们很漂亮"。

| 小节 | 时间 | 内容 | 台词（字幕） |
|---|---|---|---|
| 前奏 | 0–2.07 | 最亮最好看的一张脸 + 片头字；小窗半拍一个弹出，越弹越暗 | 请选择你的英雄 |
| 1–2 | 2.07–5.92 | 进鼓，三张冲你笑的陌生脸 → 红裙女：脸 → 跳舞 → 战场（同一个举手动作接过去） | 拜托，我是个明星 |
| 2–3 | 5.0–6.93 | 蓝衣女半拍连切 4 镜（流血、邪笑），然后定住 0.7 秒 | 你让我意识到我作为主体的存在 |
| 3–4 | 6.93–9.77 | 星期三瞪镜头（像在回上一句）+ 放射光；小女孩；一个嫌弃的反应镜头 | 你是想吓唬我吗 / 给你一篮子吻 |
| 5 | 9.77–10.77 | 女巫：全片最暗最静的一秒（高潮前的吸气） | 我就是那个女巫 |
| 5–6 | 10.77–13.63 | 同一个演员换片亮出来 → 小丑女举枪 → 两镜笑着走 → 低头伸手；**一句话跨 4 张脸，连续 5 刀甩入** | 我要……吃了你的灵魂 |
| 7 | 13.63–15.07 | 开场那张脸回来，俏皮；画框套画框把她复制成很多个 | 我是苏 |
| 8 | 15.07–17.37 | 冷脸、正面、直视、不动；转场换成失焦，最后三刀零特效；音乐一停片子就停 | 我们很漂亮 |

- **切点**：进鼓以后 34 个主切点全落在拍上（±2 帧）；只有一处半拍连切、一处跳过一拍。台词不决定切点，压在切上面说；声音比脸早半拍。
- **情绪不靠切得更快**：靠转场强度递增（高潮连甩）、台词分量递增、一句话拆给几个人、高潮前最暗最静、看镜头。
- **画面**：单人、居中、近景、约 8 成看镜头、每镜一个表情或动作的峰值；每个角色按脸 → 身体 → 世界给 1–5 镜；相邻角色换主色。
- **5 条规矩**：先数小节再定内容；每人一句能单独成立的宣言，排成递进；切点永远在拍上、台词压在切上；每镜单人居中近景看镜头；情绪靠处理强度推，结尾去掉特效停在一张看着你的脸上。

## C 单人物情绪（24.5 秒，"终于自由了 / 在错误中自由了"）

一个被修道院规训的女孩，从顺从到反抗，挨打、尖叫，最后带着伤站在光里。**结局先行，倒叙。**

| 段 | 时间 | 内容 | 镜头 |
|---|---|---|---|
| 结局先行 | 0–5.8 | 自由了的她，正面直视镜头说两句话，最后一秒歪头一笑；音乐 4.0–5.75 秒十六分音符连击蓄力 | 1 镜 5.8 秒 |
| 倒回去：压迫 | 5.8–12.1 | 落拍翻成冷色泪眼；俯拍、捂嘴、瞪眼；说出"厌倦了假装的顺从"后垂眼；一排女孩、俯拍修女 | 0.47–0.74，中间一个特效踩八分音的 2 秒长镜头 |
| 转向 | 12.1–15.2 | 中景直视，人不动、身后的世界从冷换暖；遮罩一层层推到大特写 | 先停 1.0，再 0.4–0.9 |
| 失控 | 15.2–18.8 | 仰头张嘴 → 喊 → 脸上有伤 → 乱发喘气 → 放声大笑 | 0.4–0.9，每镜都叠转场 |
| 高潮 | 18.8–20.8 | 退到中景：修女打她、她甩头（"因"）→ 特写尖叫 | 0.77 → **1.23 不切**（全片最响） |
| 落地 | 20.8–24.5 | 小节线上硬切到平静（脸上有伤）；一个人站在光里的全景；推回特写；看镜头、慢慢压暗 | 0.77 0.73 0.90 1.33 |

- **切点**：主切在小节线上（每 2.5 秒换一个情绪单元），小切踩拍和八分音，出点等动作做完（垂眼、甩头、笑到最开）。
- **体感快和真实快分开**：真换画面约 0.75 秒一次，但转场把每镜前半段填满，观众觉得 0.3 秒就有东西在变。（这一手法我们不学密度。）
- **画面**：只有她一个人（除了那个"因"）；脸占画高 60–90%；直视 = 宣言，低头 = 顺从；冷 = 被困，暖 = 自由；两个全景一前一后对照（在一排人里 / 一个人在光里）。
- **5 条规矩**：结局先行、用一句悖论开口、第一刀压在落拍上并翻颜色；按表情状态排镜头，不按事件；主切踩小节线、细切踩拍、出点等动作做完；快段前后各一个"停"，最大的停给高潮；颜色和景别讲故事，脸永远在中线。

## D 主题群像（42.4 秒，友谊）

"好朋友千载难逢 → 一起疯过 → 互相确认 → 害怕失去 → 留下空位"，一段友谊的一生压在 42 秒里。曲子是一首流行歌的副歌。

| 段 | 时间 | 内容 | 切点听谁 | 镜头均长 |
|---|---|---|---|---|
| 立论 | 0–10.63 | 车里一场对话：男生来来去去，好朋友千载难逢 / 要抓紧友谊 / 谁也不知道未来会怎样；片名 9.75 秒出，镜头糊掉，**10.63 落拍**（离音头 2 毫秒） | 句子 | 5.3 |
| 欢乐 | 10.63–24.0 | 群像：跑、跳、笑、唱、抱、走；歌词逐词出；自拍三连是能量高潮 | 歌词的词 | 0.79 |
| 确认 | 24.0–34.53 | 白闪 + 冷色雪地，歌词停；"你可以喜欢我吗"→ 分屏右边黑 0.4 秒 → "我已经喜欢你了"（暖光）→ 七镜拥抱 → "你是我最珍贵的朋友"→ "我会回来的" | 台词的短语，一句 3–5 镜 | 0.70 |
| 高潮 | 34.53–39.13 | 同一对人三镜："我不想失去你"→ 0.5 秒真空口 → "我也不想失去你" | 一句一镜，先脸后声 | 1.53 |
| 尾声 | 39.13–42.37 | 海滩上两把空着的沙滩椅，慢推，小字署名，音乐淡出 | — | 3.24 |

- **切点**：只有几扇大门卡在音乐硬点上（误差 2–22 毫秒），其余跟词走，全片只有 21% 对在拍上。
- **整体响度全程几乎不变**：变的是人声和伴奏谁占上风（开头人声压过伴奏，副歌伴奏反超，对白段打平，结尾只剩伴奏）。
- **镜头怎么挑**：人数漏斗（2 → 群像 → 2 → 同一对 → 0 人 2 把椅子）；动作越来越轻（跑 → 抱 → 点鼻子、摸头发）；每一镜都至少两个人或另一个人的一部分；看对方不看镜头；台词尽量放回它原出处的画面上。
- **特效只在门上**：片名糊出、自拍闪光、白闪、分屏、暖光。其余全部硬切。
- **5 条规矩**：先用一句话立题再用画面举例，片名在台词说完、落拍之前；切点听意思，只有大门听音乐；每一镜拍到关系；台词接成递进的对话链，问和答之间留空；节奏慢—快—急停—慢—最慢，用光和颜色做段落门，结尾一个没有人但有象征的画面停 3 秒。
