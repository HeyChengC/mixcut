# 音乐：挑曲子、读形状、截段、接缝

第 2 站（找配乐）和第 3 站（排段落表）用。片子的结构挂在曲子的形状上，所以先读懂曲子，再排段。

## 1 挑曲子

- **给片名**：默认用这部片自己的配乐（用户第一条测试片就是这么要求的："就用《星际穿越》的那个 BGM"）。
- **给主题**：挑一首形状清楚的曲子：有安静的开头、一段蓄力、一个明显的落拍、一段最满的、一个干净的收尾。有歌词的歌也行（D 用了一首流行歌的副歌，屏幕上的字跟着歌词逐词出）。
- 下载：`fetch.py music "<曲名 作者>" --dir assets/music`（取搜索第一条，只要音频）。下错版本（现场版、加长版）很常见，看一眼时长和标题。

## 2 读形状

```
python music.py analyze assets/music/x.m4a      ->  x.m4a.beats.json + x.m4a.beats.png
```

它会打印：速度、拍子网格离真音头有多近、每一段的起止和响度（section）、落拍（drop：后 8 拍比前 8 拍响 4 dB 以上、落在小节头上的那一拍）。`beats.png` 是一张响度曲线图，缩到 1000 宽以内再看。

把曲子读成这样一张表，再往上挂段落（Cornfield Chase，127.93 BPM，一拍 0.469 秒）：

| 原曲 | 是什么 | 拿来放什么 |
|---|---|---|
| 0–32 秒 | 安静前奏，约 -34 dB（拍子不太可信） | 结尾垫底（第 5 节） |
| 32–42 秒 | 蓄力，-31 → -25 dB | **冷开场**：三句台词 |
| 42.6 秒（第 90 拍） | **落拍**：-12.7 dB，低频从 20 跳到 45 | **第一刀**（点火） |
| 44–82 秒 | 平台，约 -17 dB | 离开、时间 |
| 84 秒起 | 第二次抬升，一路涨到 110–118 秒最强（-10.5 dB） | **能量高潮**（只取最强的末尾 11 秒） |
| 119.5 秒（第 254 拍） | 戛然而止，之后 7 秒衰减到无声 | 高潮急停；后面的台词在真空里说 |

参考片的曲子也是这个形状：D 前 6.75 秒只有很轻的垫乐 → 3.5 秒蓄力（低频 0 → 32）→ 10.6 秒落拍 → 副歌 → 对白段歌退半步 → 淡出；C 前 4 秒稀疏 → 1.75 秒十六分音符连击 → 5.8 秒落拍 → 一堵平的墙 → 结尾渐弱。

## 3 截段和接缝

片子 40–55 秒，曲子往往 2–4 分钟：截 2–4 段接起来。剪辑表里写：

```json
"music": {"file": "../assets/music/x.m4a", "xfade": 0.05,
          "segments": [[33.198, 55.697], [70.686, 78.184], [108.201, 122.751], {"from": 3.0, "to": null, "xfade": 1.5}]}
```

`[a, b]` 是原曲的秒；`{"from", "to", "xfade"}` 可以单独给这一段设交叉淡化；`{"rest_beats": 2}` 是 2 拍的静音（只在要"黑一下"时用，最多 2 拍）；`null` = 放到结尾。各段的拍子会接成时间线上的一条拍子网格，`bN` 按时间线数。

**接缝放在小节线上，先打分再定：**

```
python music.py seams assets/music/x.m4a --out 50-58 --in 68-80 [--n 8] [--bars 1]
```

`--out` 是曲子可以离开的范围，`--in` 是可以接回来的范围，它列出最好的几对小节线：

| 分数 | 意思 | 怎么看 |
|---|---|---|
| harm | 接上的那一小节，和原本下一小节的和声像不像 | 越高越顺；0.9 以上几乎听不出接过 |
| ctx | 两边前一小节的和声像不像 | 高 = 接进来的地方本来就在同一个调上 |
| tex | 两边的音色像不像 | 低 = 听得出的对比切（段落交接时可以故意要） |
| dE | 接进来以后响度变了多少（dB） | 往上跳正好进高潮；往下掉适合急停 |
| phr | 两边在 8 小节乐句里的位置 | 相等 = 乐句位置不乱 |

想要无缝：harm 高、tex 高、phr 相等。想要一个听得出的段落门：tex 低、dE 大，切点上配一个转场。

《星际穿越》v4 的两个接缝：第 118 拍 → 第 150 拍 harm 0.98；第 166 拍 → 第 230 拍 harm 0.99、响度往上跳 4.6 dB，正好进高潮。

## 4 拍子网格

- `analyze` 先粗跟拿速度，再细跟，最后把拍子拟合成一条稳定的网格（跟踪器本身会抖一帧、会跳着追）。打印里"多少拍子 25 毫秒内有音头"能看出网格在不在真拍上；Cornfield Chase 是 69%，错开半拍只有 21%。
- 安静段（前奏）的拍子不太可信，大门不要放在那里。
- 剪辑表里：`"beats": 1` 一拍，`0.5` 半拍，`2` 两拍；`"at": "b20"` 第 20 拍。
- 大门那几刀（落拍、段落交接）要落在真的音头上：`beats.json` 的 `accents` 里有每个音头和它有多突出，渲染后在 `timeline.json` 里核，离音头不超过 1 帧。

## 5 台词和音乐

- **台词比底下的音乐高 8–10 dB**。渲染时每句都会打印人声、底下的音乐、差值，低于 +8 dB 标 "music too loud"。v2 是 +10 到 +16，音乐太小，片子没了劲。
- 说话时把音乐压低多少（`duck_db`）：冷开场 -3（音乐本来就轻）；对白段 -10；高潮那一声喊 -13。
- 呼吸靠把人声拿走、画面停住，不靠把音乐静音（D 全片没有一处音乐静音）。
- 成片约 -14 LUFS，真峰值不超过 -1 dBTP（`qc.py` 会量）。

## 6 曲子先收了、话还没说完

《星际穿越》v4 结尾：原曲 119.5 秒戛然而止，后面只有 3 秒尾音，可还有 4 句台词要说。做法：第一句在真空里说（"It was you"），然后把原曲安静的开头（风琴，从 3 秒起）用 1.5 秒的长交叉淡化垫进来（上面 `segments` 的最后一段）。这一处是"按推荐做了、请用户确认的"。

## 7 听不到声音

我们听不到声音。接缝顺不顺、台词和口型对不对、喊声接在哪张脸上，都是按数和时间码对的。交付说明里如实写"没听过"，列出请用户重点听的地方（每个接缝、每句借来的声音）。
