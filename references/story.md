# 内容逻辑：先有一句话，再有画面

第 1 站（立意）和第 3 站（段落表）用。三条参考片没有一条是"把好看的镜头按节拍排一遍"，都是**把不同片段的台词接成一句新的话或一段新的对话**，画面替这句话服务，最后落在一句话或一个画面上。

## 1 立意 → 立论句 → 兑现

**立意**是给自己的：一句话说这条片讲什么。《星际穿越》："父亲答应女儿会回来，这句话穿过了几十年。"

**立论句**是给观众的：原片里的一句台词，开场 5–10 秒说出来，把题立住。它要：

- 能单独成立（不看片也懂）；
- 有态度，观众听完会站队；
- 带一个钩子，让人想看下去；
- 给结尾埋伏笔。

四种开法，四个长得不一样的例子：

| 开法 | 例子 | 钩子是什么 | 结尾怎么兑现 |
|---|---|---|---|
| 一个人人认同的观点 | D："男生来来去去，好朋友千载难逢……谁也不知道未来会怎样" | 后半句"未来不知道"是不安 | 两把空着的沙滩椅 |
| 结局先行 + 悖论 | C："终于自由了 / 在错误中自由了" | 自由为什么在错误里？ | 最后一镜回到开头那个她，不说话，看着你 |
| 给规则 | A："请选择你的英雄" | 下一个会是谁？ | 一句复数的"我们很漂亮" |
| 一个谜 | 《星际穿越》："Once you're a parent, you're the ghost of your children's future." | 什么鬼魂？ | 书架后的"鬼魂"就是他自己，长大的女儿说："It was you. You were my ghost." |

> 好：能当片名的一句话，有判断、有对象（"好朋友千载难逢"）。
> 坏：交代情节的句子（"We need to go."），或者空泛的口号。
> 差在哪：前者让后面每一镜都成了它的例子；后者只是剧情的一帧。

**门：找不到立论句就不开剪。** 去别处找：片中独白、预告片里的旁白、主演在特辑里的一句话、片尾的一句。还找不到，和用户商量换个角度或换题。

## 2 台词接成一条越说越重的链

中段的台词不是随便挑几句名台词，而是一条递进的链，**每句比上一句重**：

- D：你可以喜欢我吗（试探）→ 我已经喜欢你了（接纳）→ 你是我最珍贵的朋友（命名）→ 我会回来的（分离的预兆）→ 我不想失去你 → 我也不想失去你。
- A：我是个明星（虚荣）→ 你让我意识到我作为主体的存在（更深）→ 你是想吓唬我吗（开始回嘴）→ 给你一篮子吻（落一下）→ 我就是那个女巫（身份）→ 我要……吃了你的灵魂（最狠）→ 我是苏（回到开头）→ 我们很漂亮（收成"我们"）。
- 《星际穿越》：你根本不知道自己什么时候回来（不信）→ 我会回来的（答应）→ 23 年 4 个月 8 天（代价）→ 现在正是你回来的好时候（呼唤）→ STAY（想留住自己）→ 是你，你就是我的鬼魂（揭开）→ 我知道你会回来，因为我爸答应过我（兑现）。

链里常用的几种接法：

- **问和答跨片子**：D 一部片问"你可以喜欢我吗"，另一部片答"我已经喜欢你了"。A 一个角色说"你让我意识到我的存在"，下一个角色像在回嘴"你是想吓唬我吗"。
- **反应镜头当回话**：A 有人说"给你一篮子吻"，下一镜一个角色托着下巴一脸嫌弃。名单变成了群聊。
- **一句话拆给几个人说完**：A "我要……吃了你的灵魂"跨了 4 张脸，观众要等到第 4 张脸才听完。这是悬念，放在高潮。
- **同一个词贯穿**：《星际穿越》的 "come back" 在四句台词里出现，就是这条片自己的语言。
- **问句后留空**：D 问完，分屏右边黑 0.4 秒才出回答的人，声音再晚 0.7 秒。

台词就近取材：**台词和画面尽量出自同一部片、同一场戏**，观众听着不别扭（D 把问句放回它原出处的画面上，"你是我最珍贵的朋友"用那部剧自己的三个镜头来说）。借声音时（画面是 A 场，声音是 B 场），要口型对得上或者看不见嘴。

台词要短：只留关键短句，长句砍到最有分量的几个词。v2 一句话一个长镜头、台词全长放，片子就成了预告片。

### 怎么做

1. 所有素材 `lines.py --sep` 转写，`lines.py find` 搜关键词。
2. 把候选台词抄成一张表：句子、出处、源秒、谁对谁说、分量（1–10）、能接上哪句。
3. 先定首句（立论）和尾句（兑现），再从分量低到高往中间填。删掉只交代情节的句子。
4. 只读这张表（不看画面）念一遍：能听出起—承—转—落 = 对。

## 3 画面在讲"状态"，不是"事件"

每一镜回答"此刻是什么状态、什么关系"，不回答"发生了什么事"。**镜头跟着台词挑**，不是先挑好看的镜头再配话。

几条能直接拿来排镜头的线（一条片选一两条用，不用全用）：

| 线 | 例子 |
|---|---|
| 人数越来越少 | D：2 人 → 3–5 人的群像 → 2 人 → 同一对 2 人 → 0 人、2 把椅子 |
| 动作越来越轻 | D：跑、跳 → 躺、贴耳朵 → 抱 → 点鼻子、摸头发 |
| 表情一级级放开 | C：闭嘴低头 → 瞪 → 张嘴仰头 → 喊 → 大笑 → 尖叫 → 平静 |
| 看不看镜头 | C：直视 = 宣言、对抗；低头闭眼 = 顺从、内心；前半段两种来回拉扯，最后定在看镜头上 |
| 颜色 | C：冷青 = 被困，暖金 = 自由；D：越往后越褪色，像回忆；《星际穿越》：时间那段整段偏冷 |
| 景别往里推 | D：全景群像 → 双人近景 → 脸贴脸特写 → 单人闭眼特写 |
| 年龄 / 年代跨度 | D：小孩、少女、中年都有，说的是"友谊"本身，不是哪一部剧 |

**每一镜都要有人**（`picture.md`）。单片混剪最容易滑向"讲事"：火箭、飞船、爆炸一镜接一镜。《星际穿越》v4 第一轮预览里，离开那段有 3 秒只有一张脸，审片的结论是"在讲事，不是讲人"。

## 4 片名模式和主题模式

**给片名**（测试过一次）：

- 在整部片里找一条"一句话穿过整部片"的线：一个承诺、一个问题、一个词（"come back"）。
- 素材：几版官方预告（同一部片不同版本镜头不一样）、片段频道的整场戏（台词全，但有黑边和水印）、特辑。
- 默认用这部片自己的配乐（用户的要求）。

**给主题**（还没跑过）：

- 先列 6–12 部候选片。每部至少要能贡献一句接得上链的台词，或者一个能给主题举例的状态。只有一个好看镜头、没有台词的片子不要。
- 有观众一眼认得的脸（A 的星期三、小丑女），这是钩子。
- 年龄、年代、类型拉开跨度，说明讲的是这件事本身。
- 配乐选一首形状清楚的曲子（`music.md`），有歌词的歌也行（D 用了一首流行歌的副歌，歌词逐词出字）。
- 第一次跑完，把选片的坑补进这一节。
