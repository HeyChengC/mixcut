# 用户说过的话

用户看片时说过的话 → 变成了哪条规则 → 管多大范围。新的话加在最下面，原话照抄，不改写。

| 什么时候 | 原话 | 变成的规则 | 范围 |
|---|---|---|---|
| 立项 | "我想做一个混剪风格的 skill，你可以仔细参考这几个参考视频，它混剪做的都挺好。我不管你从什么方法能做出来，我需要你从这个行业顶级专家入手，去思考如何最简洁地剪辑，像剪辑大师一样做一个这样的剪辑风格 skill。" | 先有剪辑的逻辑，再有技巧；最简洁 | 这个风格 |
| 立项 | "效果就是你自己去找素材，然后自己混剪。我只需要给出主题，或者给出电影名，你就可以自己完成对应的混剪。" | 找片、下片、配乐全自己来；两个入口：主题、片名 | 这个风格 |
| 立项 | "我最终要的是效果，效果你必须反复自己迭代好几次再说。" | 交付前至少两轮审片和修改（`production.md` 第 2 节） | 所有片 |
| 第一条测试片 | "你不是要剪星际穿越吗？就用《星际穿越》的那个 BGM，然后挑选里面一段，做一个混剪片子，要有 BGM。" | 给片名时，默认用这部片自己的配乐 | 片名模式 |
| 看完 v1 | "成片效果还行，但可以加一些文字效果、转场效果之类的。你看过参考视频了吗？还可以再迭代。要有自己的叙事逻辑、剪片逻辑，可以参考参考视频里的。得让片子像一个剪出来的片子，剪完要能讲出一个故事，能表达这个片子的意义，或者有它自己的语言，不是为了剪而剪。"（转述，大意） | 每条片先写立意和段落表；挑不出意义的镜头不要；门上要有字和转场 | 这个风格 |
| 看完 v1 | "混剪的文字特效和转场要克制且高级，有自己的顶级品味。" | 特效只在门上；好字体，不描边不发光不弹跳；拿不准就不加 | 这个风格 |
| 看完 v2 | "咋说呢 这是混剪吗 你能不能学学参考视频啊 你自己仔细对比一下参考视频再做把" | 节奏要像混剪不像预告片：一拍一切、台词压在快切上；交付前和参考片对数 | 这个风格 |
| v3 做到一半 | "我觉得你再看看参考视频 是咋剪辑的？剪辑逻辑是啥？内容逻辑是啥？画面如何保证？如何引导情绪？如何掌握节奏？如何完成开头 高潮 结尾的这些才是最重要的" | 学逻辑，不只学指标。这六个问题就是 `references/` 的骨架：editing、story、picture、rhythm、arc | 这个风格 |
| 做字的时候 | "混剪自己选一个推荐的就行。" | 字体和样式不做样张给他挑，按 `type.md` 的推荐定，说明里写一句理由 | 这个风格 |
| 工作室规矩 | "不要说我在睡觉了，该让我决定的我来决定" | 立意、结构、审美取舍、删东西、发布：做出备选或按推荐做，交付时列出来请他定 | 所有片 |
