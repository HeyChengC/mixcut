# 开头、高潮、结尾

用户原话："如何完成开头 高潮 结尾的这些才是最重要的。" 排段落表、写这几段的镜头时用。

## 开头

### 头 2 秒：一张脸 + 一句话

第一帧就要有一张脸，和一句话（或一条规则）。

| | 头 2 秒给了什么 |
|---|---|
| D | 车里两个女生的双人中景，暖、静；一行占画高约 10% 的大字幕"男生们可能来来去去" |
| C | 一张正面直视镜头的特写（脸占画高 80%），开口说"终于自由了" |
| A | 全片最亮最好看的一张脸，脸前浮着一行"请选择你的英雄"，然后十几个角色的小窗半拍一个弹出来 |
| 《星际穿越》v4 | 库珀坐在熟睡的女儿床边，手搭着她；上方暗处出大字"当了父母，你就成了孩子未来的鬼魂" |

不要：黑场淡入很久、空镜、一张片名卡占满开头。

### 头 5–10 秒：冷开场

- **立论句说完**，观众已经站了队。D 的第一句是金句不是铺垫，3 秒内拿到观点。
- **1–3 个长镜头**，在句子之间的气口切（D 第一刀在第一句说完 0.77 秒后）。画面干净、只有一个变化，注意力全在台词上。
- **字大**，静音刷也看得懂（`type.md`）。
- **音乐在蓄力**，观众等着它炸。
- **片名**在最后一句说完、落拍之前出来（D 9.75 秒），叠在最后一个冷开场镜头上，镜头糊掉、片名留着跨过落拍那一刀，下一镜从暗里亮起来再淡出（`transitions.md` 的 `blur_dark`）。
- **第一刀卡死在落拍上**，同时翻颜色或翻表情：C 暖色笑脸 → 冷色泪眼（告诉观众"倒回去了"）；D 暗、糊 → 一群人冲着镜头跑来（"出发了"）；《星际穿越》→ 火箭点火，糊着过曝切进去（动机是火光）。

为什么不划走（D）：第一句就是观点；字大；画面干净；耳朵里有蓄力；片名出现的那一下就是"章节开始"。

> 坏：我们的 v3 开头 0–9 秒又轻又碎，没有立论句，没有蓄力和落拍。
> 好：v4 开头三个长镜头说完三句话，片名压在第三镜上，第一刀落在落拍。

## 高潮

### 在哪

全片 70–90% 的位置（C 80%，D 82–92%）。《星际穿越》v4 的能量高潮停在 STAY（约 73–76%），情感高潮在后面的"是你……因为我爸答应过我"。

### 之前要铺什么

1. 开头那句话里埋下"会失去 / 会分开 / 有代价"（D "谁也不知道未来会怎样"）。
2. 一段快乐或一段能量，让观众知道这些人有多好，失去才会疼。
3. 台词链推到"分离的预兆"（D "我会回来的"）。没有这一步，高潮那句会显得突然。
4. 一段最暗最静的吸气（A 女巫段；C 退到中景交代起因）。

### 能量高潮怎么剪

越切越碎：2 拍 → 1 拍 → 半拍；转场越来越密（A 连续 5 刀甩入）；景别越来越近；音乐最满。然后**急停**。

### 情感高潮怎么剪

- 一句一个镜头。先给脸 0.3 秒再出声，说完留 0.2–0.4 秒。
- 景别比前一镜近一大步（C 从中景双人一下推到特写）。
- 速度比前面慢一倍多（D 1.83 / 1.30 / 1.47 秒）。
- 同一对人连着几镜，观众不用再认新的人，情绪可以连着走（D 最后三镜同一部片的同一对人）。
- 声音：人声冲上来，伴奏不变或者干脆没有；问和答之间留一个真空口。
- 大字只给这一处的一个词（《星际穿越》STAY），字下面的画面压暗垫底，不描边。

> 好：C 修女出手 → 她甩头（中景，0.77 秒，交代"因"）→ 特写尖叫 1.23 秒不切 → 小节线上硬切到平静。
> 坏：v3 的 STAY 0.47 秒一闪而过，下一拍就切走。

## 结尾

### 回到开头

| 闭环的方式 | 例子 |
|---|---|
| 同一个人回来 | C 最后一镜和第一镜是同一个她（暖色、盘发、看镜头）；A 开场那张脸在倒数第二段回来 |
| 兑现开头那句话的象征画面 | D 两把空着的沙滩椅 = 两个人，空着 = "未来不知道" |
| 同一个构图，角色倒过来 | 《星际穿越》开头他坐在熟睡的她床边；结尾老年的她躺在床上，他坐在床边握着她的手 |

### 最后一镜

- 停 1.3–4 秒（A 是名单片，一拍一切到最后，靠去掉特效、去掉运动、先暗再亮来收）。
- 去掉特效，去掉运动（不推镜或很慢地推）。
- 和音乐的收尾一起收：曲子渐弱就跟着淡出（`end_fade`）；曲子戛然而止就停在那。
- 高潮之后先降温：C 在小节线上一刀从尖叫硬切到平静；D 把人拿走，"空"才显得出前面的"满"。
- 不给答案：D 的椅子空着，可以是去散步了，也可以是分开了，悲还是暖由观众自己定。
- 可选：一行很小的署名（片名、年份），正中。

### 曲子先收了、话还没说完

《星际穿越》v4：原曲在 119.5 秒戛然而止，后面只剩 3 秒尾音，可结尾还有 4 句台词。做法是让原曲安静的开头（风琴）用 1.5 秒的长淡入垫在后面（`music.md`）。台词先在真空里说一句，再让风琴进来。

> 坏：v4 第一轮预览里，最后两镜机位一模一样，切点像卡了一下；最后一镜里看不到他，和开头接不上。
> 好：把最后一镜的裁切中心挪到她在左、他的后脑在右，正好是开头那一镜倒过来。
